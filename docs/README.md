# Documentación del proyecto

En esta carpeta se almacenan los documentos y materiales de apoyo correspondientes al Proyecto Semestral de Programación I.

## Contenido

- **Documento del avance:** contiene la descripción del proyecto, el escenario asignado y los requerimientos establecidos para el desarrollo del sistema.
- **Diagrama UML:** representa gráficamente las clases del Sistema de Gestión de Tienda de Tecnología, sus atributos, métodos y relaciones.

## Propósito

Mantener organizada la documentación utilizada durante la planificación y el desarrollo del proyecto.

- Actualizar la documentación conforme evolucione el sistema.
