# Sistema de Gestión de Tienda de Tecnología

**Proyecto Semestral – Programación I**

**Universidad Tecnológica de Panamá**

## Descripción del proyecto

El Sistema de Gestión de Tienda de Tecnología es un proyecto desarrollado para representar y administrar las operaciones principales de un negocio dedicado a la venta de productos tecnológicos.

El sistema contempla diferentes procesos relacionados con la administración de clientes, empleados, productos, proveedores, inventario y ventas, así como el manejo de facturas, devoluciones y garantías.

## Objetivo

Desarrollar un sistema que permita organizar las operaciones de una tienda de tecnología mediante la aplicación de los conceptos de programación orientada a objetos aprendidos en la asignatura de Programación I.

## Componentes del sistema

El proyecto contempla las siguientes clases:

| Clase | Descripción |
|---|---|
| Usuario | Manejo de usuarios y permisos. |
| Empleado | Registro y atención de clientes. |
| Cliente | Información e historial de compras. |
| Proveedor | Administración de proveedores. |
| Categoria | Clasificación de productos. |
| Producto | Información y precios de productos. |
| Inventario | Control de existencias. |
| Venta | Registro de operaciones de venta. |
| Factura | Generación de facturas. |
| Devolucion | Gestión de devoluciones. |
| Garantia | Control de garantías. |
| Reporte | Consulta de información de ventas y compras. |

## Organización del proyecto

- `src/`: contiene el código fuente desarrollado en Java.
- `docs/`: contiene la documentación y los materiales relacionados con el proyecto.
